# Moved to pi-turnkit

This package is now part of [pi-turnkit](https://github.com/kcurtet/pi-turnkit),
which unifies it with use-cheap (and future turn-scoped modes):

```bash
pi uninstall git:https://github.com/kcurtet/pi-think-hard
pi install git:https://github.com/kcurtet/pi-turnkit
```

The `+` prefix works exactly the same; configuration is now
`/turnkit config + provider/model/level`.
